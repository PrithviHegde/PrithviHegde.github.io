# Tool icons

- `aws-*.svg`: official AWS Architecture Icons (service icons, 32 px set), from the icon package dated 31 July 2026 at https://aws.amazon.com/architecture/icons/. Used unmodified to name the AWS services a project was built on.
- All other files: marks from Simple Icons (https://simpleicons.org), version 13.0.0 (Ollama from 14.0.0), filled with each brand's colour from the same package. The marks themselves belong to their owners and are used only to name the tools a project uses.

The tags use these only where a tool has a well-known mark; every other tool is shown by name alone.
